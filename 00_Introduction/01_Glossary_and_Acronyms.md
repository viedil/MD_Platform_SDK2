# Glossary and Acronyms

**Version:** 0.9.0

**Owner:** Platform Team

## A

| Term | Definition |
|------|------------|
| **API** | Application Programming Interface - defined interfaces for software components to communicate |
| **A/B Testing** | Method of comparing two versions of a model or algorithm to determine which performs better |
| **ACL** | Access Control List - security mechanism defining permissions for resources |
| **AES** | Advanced Encryption Standard - symmetric encryption algorithm (128/256-bit) |
| **AHAB** | Amazon Hardware Attestation Block - Qualcomm secure boot component |
| **ALSA** | Advanced Linux Sound Architecture - kernel API for audio devices |
| **ARM TrustZone** | Hardware-based security extension providing secure and normal worlds |

## B

| Term | Definition |
|------|------------|
| **BSP** | Board Support Package - low-level software for hardware initialization |
| **BOM** | Bill of Materials - list of components and dependencies |
| **SBOM** | Software Bill of Materials - inventory of software components and licenses |
| **BootROM** | Read-only memory containing initial boot code |
| **BL31** | ARM Trusted Firmware runtime firmware (EL3 level) |

## C

| Term | Definition |
|------|------------|
| **CE Mark** | Certification marking for products sold in European Economic Area |

| **CVSS** | Common Vulnerability Scoring System - vulnerability severity rating |
| **CMA** | Contiguous Memory Allocator - Linux kernel memory allocator |
| **CPU** | Central Processing Unit |
| **CUDA** | Compute Unified Device Architecture (NVIDIA GPU computing platform) |

## D

| Term | Definition |

| **DRM** | Direct Rendering Manager - Linux kernel subsystem for GPU access |
